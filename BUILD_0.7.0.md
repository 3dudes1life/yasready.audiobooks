# 0.7.0 — Review Studio

Adds the human approval layer for YasReady Audiobooks.

- Review sessions and per-chapter review state
- Take A/B/C registration from ready Production Engine jobs
- Waveform/transcript asset locators
- Synchronized canonical review regions with per-take timings
- Region-level take approval and rejection
- Audited regeneration requests without automatic rendering
- Chapter progress + take matrix for UI consumption
- Approval locks that protect accepted audio from silent replacement
- Audited chapter/session unlock workflow
- Smarter installer: auto-clones the GitHub repo when no local checkout exists

No provider calls are required by this build.
