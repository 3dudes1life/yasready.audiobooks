# 0.5.0 — Audiobook Director

Adds the non-destructive performance-direction layer.

- scene/segment performance direction
- emotional arc summaries
- pacing, intensity, restraint, volume and pause control
- conservative Eleven v3 audio-tag compilation
- immutable canonical manuscript text
- fail-closed dialogue requiring canonical speaker bindings
- optional analysis adapter for future AI director intelligence

No audio generation is required by this build.
